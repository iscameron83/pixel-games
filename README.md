# Pixel Games

Small, hand-built browser games. Each lives in its own folder and is a self-contained HTML file, playable via GitHub Pages.

## Games

- **[Mango Cay](mango-cay/)** — a point-and-click pixel pirate adventure.
- **Car Game** — in progress.

## Playing

Once GitHub Pages is enabled, the collection is live at:

- Landing page: `https://iscameron83.github.io/pixel-games/`
- A game directly, e.g.: `https://iscameron83.github.io/pixel-games/mango-cay/`

## Adding a game

1. Create a folder named after the game.
2. Put the game in it as `index.html` (so it serves at `/<folder>/`).
3. Add a card for it in the root `index.html`.
